# מי מהמשפחה? – איברים דומים

משחק Prismind / פריזמה לכיתה ז׳: זיהוי איברים דומים (גם כשהם "מחופשים": `yx`, `x·x`, `x` בודד) וכינוס שלהם – בלי הקלדה.

## מהלך
- על גג הבית כתוב שם המשפחה. לוחצים על כל בני המשפחה (או גוררים אותם לבית) ונזהרים ממתחזים.
- כשכל המשפחה בבית – בוחרים את הכינוס הנכון מתוך 4 אפשרויות (המסיחים בנויים מטעויות נפוצות).
- 4 שלבים × 4 משפחות: x ומספרים · מקדמים שליליים · x² מול x · שתי אותיות (xy / yx / x²y).

## מנגנונים
לבבות (3 לשלב), מטבעות (1 לבן משפחה, 3 לכינוס), רצף, רמז (2 מטבעות), כוכבים בסוף שלב, גביע בסיום.

## קבצים
`index.html` – קובץ אחד עצמאי. הפונט, הלוגו, האייקונים והצלילים (מתיקיית prisma) מוטמעים בו.
